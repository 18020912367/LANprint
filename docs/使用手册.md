# LANPrint 使用手册

> 面向最终用户的操作指南：把“服务端电脑接的真实打印机”共享给局域网内其它电脑使用。
> 当前适用版本：服务端 v1.0.0、客户端 v1.0.4。

---

## 1. 这是什么？

两台电脑在同一个局域网内：

- **服务端**：接了一台真实打印机（USB / 网络打印机均可）的电脑；
- **客户端**：没有打印机、想借用的电脑（可以有多台）。

在**客户端**上安装一次 LANPrint 客户端，打印对话框里就会出现一台虚拟打印机
（名字形如 `192.168.1.10_前台打印机`）。选它打印，就像打印到身边的打印机一样，
纸会从**服务端**那台真实打印机出来。

- 不需要共享文件夹、不需要拷贝文件；
- Word / Excel / 网页 / 图片 / PDF 等任何能打印的内容都可以；
- 客户端打印时会先转成 PDF 再发送，版式与你在打印预览里看到的一致。

---

## 2. 总体流程（先服务端，后客户端）

```
服务端电脑：安装服务端包 → 选择要共享的真实打印机 → 记住 IP/端口/共享名
客户端电脑：安装客户端包 → 填写上面的 IP/端口/共享名 → 完成
任意电脑：   打印 → 选虚拟打印机 → 出纸到服务端 → 收到完成通知
```

**先做服务端，再做客户端。** 客户端安装时会校验“能否连上服务端”，连不上会中止安装。

---

## 3. 服务端安装与配置

> 服务端安装包：`lanprint_server_setup.exe`
> 要求：Windows 10/11 x64，已正确安装好要共享的打印机驱动并能正常打印。

1. 双击安装包，一路“下一步”（安装需要管理员权限，遇到 UAC 提示选“是”）；
2. 安装完成后会自动弹出**配置向导**（黑色命令行窗口），按提示操作：
   - 屏幕会列出本机**可用的真实打印机**（虚拟打印机已被自动过滤）;
   - 输入序号选择要共享的打印机，回车；
   - 输入共享名（默认 `我的打印机`），回车；
   - 端口保持默认 `17878` 即可，回车；
3. 向导自动写入防火墙规则，随后服务端在后台开始运行（托盘无窗口）;
4. **记下三个信息**，客户端安装时要用：
   - 服务端电脑的 IP 地址（如 `192.168.1.10`，可在服务端电脑上运行 `ipconfig` 查看）；
   - 端口：默认 `17878`；
   - 共享名：你填的名字（如 `我的打印机`）。

> 校验方式：在服务端电脑打开浏览器访问 `http://127.0.0.1:17878/status`，
> 能显示 JSON 即表示服务端正常运行。

## 4. 客户端安装与注册

> 客户端安装包：`lanprint_client_setup.exe`
> 要求：Windows 10/11 x64；需提前确认能访问服务端（同一局域网、防火墙已放行）。

1. 双击安装包（需要管理员权限，UAC 选“是”）；
2. 向导出现 **“LANPrint 服务端信息”** 页，填写：
   - **服务端 IP 地址**：如 `192.168.1.10`
   - **服务端端口**：`17878`
   - **服务端共享打印机名称**：如 `我的打印机`
3. 点“下一步”，安装程序会先自动**检测能否连上服务端**：
   - 连不上：报错并中止安装，请检查 IP/端口/网络/防火墙后再试；
   - 连得上：继续安装，完成后**自动注册虚拟打印机**并启动后台代理；
4. 安装完成后，打开系统的“打印机和扫描仪”（Windows 设置 → 蓝牙和其他设备 →
   打印机和扫描仪），应能看到名为 **`<服务端IP>_<共享名>`** 的打印机，如
   `192.168.1.10_我的打印机`。看到它即表示注册成功。

> 注意：注册需要管理员权限，已由安装程序自动完成，**不需要**你手动运行任何命令。
> 若注册失败，安装结束页会弹窗提示，并给出一行可复制的命令；以管理员身份运行该命令即可完成注册。

## 5. 日常打印

打印的方法和平时一模一样：

1. 在任意软件里按 `Ctrl+P` 打开打印；
2. 打印机选择 `192.168.1.10_我的打印机`；
3. 按需设置份数/页面范围后点“打印”。

随后会收到两条通知：

| 通知 | 含义 |
|---|---|
| “文档已发送到服务端，排队打印中” | 文件已被服务端接收，正在等待出纸 |
| “打印完成（共 N 页）” | 服务端已打印完成 |
| “打印失败：原因…” | 服务端打印出错（缺纸/卡纸/脱机等），请检查服务端打印机 |

- 打印是**排队**进行的：多人同时打印时按顺序出纸；
- 客户端断网/服务端关机时打印：任务会自动**暂存**，恢复联网后**自动重发**，无需重打；
- 托盘小圆点颜色：**绿**=服务端在线、**灰**=离线、**黄**=有暂存任务等待重发。

## 6. 网络与防火墙要求

- 两台电脑必须在**同一个局域网**，能互相访问；
- 服务端需放行 TCP `17878` 端口（安装向导已自动添加防火墙规则；
  若服务端使用第三方安全软件，请额外放行）；
- 如果客户端安装时报“无法连接服务端”，按顺序检查：
  1. 服务端电脑是否已开机并运行了 LANPrint 服务端；
  2. 客户端能否 `ping` 通服务端 IP；
  3. 服务端防火墙是否放行 17878；
  4. 是否在同一网段 / 是否开了访客网络隔离。

## 7. 常见问题（FAQ）

| 现象 | 处理方法 |
|---|---|
| 安装客户端时提示“无法连接服务端” | 见上文“网络与防火墙要求”；确认服务端已运行、IP/端口填写正确 |
| 打印机列表里看不到虚拟打印机 | 确认安装完成且未报注册失败；打开“打印机和扫描仪”刷新；仍无则按注册失败提示以管理员身份重跑命令 |
| 打印后没有反应、没有通知 | 看托盘图标是否**灰/黄**（离线或暂存）；右键托盘图标选“立即重发暂存任务”；仍不行请看服务端电脑是否出纸 |
| 打印失败提示“打印机脱机/缺纸/需要用户干预” | 到服务端电脑检查真实打印机状态（缺纸、卡纸、脱机、舱门打开等） |
| 提示“文件过大” | 服务端默认限制 200MB，联系管理员调大 `max_upload_mb` |
| 杀毒软件拦截安装包/exe | LANPrint 为 PyInstaller 打包的绿色可执行程序，可能被误报；请添加信任后重试 |
| 开机后需要重新打印才联网？ | 客户端 agent 已设开机自启（HKCU Run），登录系统即后台运行；托盘图标是运行标志 |
| 如何确认版本 | 客户端安装目录运行 `lanprint_client.exe version`；服务端为 `lanprint_server.exe version` |

## 8. 卸载

- **服务端**：控制面板/设置 → 应用 → 卸载 `LANPrint Server`。卸载时可选是否删除数据目录
  （日志与任务缓存）；防火墙规则与自启项会被自动清理。
- **客户端**：卸载 `LANPrint Client`。卸载过程会自动删除虚拟打印机与回环端口并结束后台代理；
  如提示是否删除配置与暂存数据，通常选“是”。

> 卸载客户端前请确认没有正在打印的任务，否则任务将无法送达。

---

## 9. 日志与数据位置（排障用）

所有数据位于 `C:\ProgramData\LANPrint\`：

| 内容 | 路径 |
|---|---|
| 服务端日志 | `C:\ProgramData\LANPrint\logs\server.log` |
| 客户端日志 | `C:\ProgramData\LANPrint\logs\client.log` |
| 服务端配置 | `C:\ProgramData\LANPrint\config.json` |
| 客户端配置 | `C:\ProgramData\LANPrint\client.json` |
| 客户端离线暂存 | `C:\ProgramData\LANPrint\offline\` |

排障时请把这些日志发给维护人员，能快速定位问题。

---

## 10. 版本与更新

- 客户端版本可在 `lanprint_client.exe version` 输出中查看（如 `v1.0.4`）；
- 升级方法：直接用新安装包**覆盖安装**，客户端已保存的服务端配置会自动带入，无需重新填写。
