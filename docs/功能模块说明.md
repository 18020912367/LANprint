## 4. 客户端 client/ 【二】

> **捕获链路（v1.0.3 起，本版 v1.0.4）**：
> 打印捕获不依赖任何第三方 DLL，采用 **Windows 内置 Standard TCP/IP 端口监视器（tcpmon）** 的
> **本机回环端口 `LANPRINT`（127.0.0.1:9100）** + 常驻代理 **agent 回环监听**：
> 用户向虚拟打印机打印 → `Microsoft Print To PDF`（v4 驱动）渲染为 PDF →
> spooler 将 PDF 字节流经回环 TCP 送到 127.0.0.1:9100 → agent 收完整段 PDF 后上传服务端。
> 方案演进见 [项目开发说明.md](./项目开发说明.md#7-客户端设计) 的说明。

### 4.1 client/main.py — 客户端入口（命令行分发）

| 功能 | 代码块 | 说明 |
|---|---|---|
| 版本常量 | `CLIENT_VERSION` | 当前 1.0.4；每次修复 exe 递增并与 installer 的 MyAppVersion 同步 |
| 轻量子命令 | `version` / `check-server` | 在加载配置/日志前处理，避免无 `%ProgramData%` 写权限崩溃 |
| 连通性校验 | `cmd_check_server(host, port)` | GET /ping；失败退出码 1（安装器据此中止安装） |
| 捕获入口 | `cmd_capture(cfg)` | 遗留（命令行 stdin）捕获路径；当前打印由 agent 回环接收替代 |
| 注册 | `cmd_register(server, port, share)` | 调 `setup_printer.register_client`；`_cmd_register_from_argv` 先校验连通再注册 |
| 卸载 | `cmd_unregister()` | 调 `setup_printer.unregister_client` |
| 分发主入口 | `main(argv)` | `capture / check-server / register / unregister / agent / version` |

### 4.2 client/setup_printer.py — 虚拟打印机注册/卸载（管理员）

| 功能 | 代码块 | 说明 |
|---|---|---|
| 常量 | `PORT_NAME=LANPRINT / PORT_HOST=127.0.0.1 / PORT_TCP_PORT=9100 / PRINTER_DRIVER` | 回环端口与“Microsoft Print To PDF”驱动名 |
| 显示名 | `build_display_name(server_host, share_name)` | `<服务端IP>_<共享名>`（如 `192.168.20.56_JY1020`） |
| 管理员校验 | `is_admin()` | 非管理员直接报错退出（安装器提权执行） |
| 历史残留清理 | `cleanup_legacy()` | 删除 1.0.0 Virtual Port Monitor 与 1.0.1/1.0.2 RedMon 的遗留注册表键及 System32 DLL |
| 端口枚举 | `_enum_port_names()` | `EnumPorts` 端口名集合 |
| 端口等待 | `wait_port_online(timeout)` | 轮询 LANPRINT 可被枚举 |
| 创建回环端口 | `ensure_tcp_port()` | 缺失则 `Add-PrinterPort -PrinterHostAddress 127.0.0.1`（内置监视器，兼容 v4 驱动） |
| 删除回环端口 | `remove_tcp_port()` | `Remove-PrinterPort` |
| ctypes 结构 | `_PrinterInfo2W` / `_AddPrinterW` | 直调 `winspool.drv!AddPrinterW`（pywin32 AddPrinter 转换器与 23 字段结构不兼容，见下） |
| 创建打印机 | `create_printer(display_name)` / `_ensure_driver()` | 绑定 LANPRINT 端口；驱动缺失则 `Add-PrinterDriver` |
| 幂等辅助 | `printer_exists` / `delete_printer` | 注册前清理同名旧打印机（先清空作业） |
| 注册编排 | `register_client(server, port, share)` | 管理员校验 → 清理遗留 → 建回环端口 → 删旧建新打印机 → 保存 client.json（含 local_tcp_port） |
| 卸载编排 | `unregister_client()` | 删打印机 → 删回环端口 → 清理遗留 |

### 4.3 client/agent.py — 常驻代理（托盘 + 离线重发 + 回环接收）

| 功能 | 代码块 | 说明 |
|---|---|---|
| 托盘图标 | `_make_icon_ico` / `_hicon_from_ico` / `TrayIcon` | PIL 生成三色圆点 ICO；`_hicon_from_ico` 用 user32 `LoadImageW` 从临时 .ico 加载 HICON（兼容缺 `CreateIconFromResourceEx` 的 pywin32）；绿=在线、灰=离线、黄=有暂存；右键菜单（立即重发/退出） |
| 主循环 | `Agent.loop(tray)` | 每 10 秒 GET /ping 更新状态；每 2 秒消费通知目录弹用户通知 |
| 通知消费 | `Agent._on_notification` | Toast 优先，失败降级弹窗 |
| 离线重发 | `_count_stashed` / `_resend_worker` / `_retry_one` | 恢复在线后逐条重发暂存任务（2 秒节流），成功/终态失败后清理 |
| 回环接收 | `RedirectListener` | 监听 `127.0.0.1:9100`（daemon 线程）；每连接一个打印作业，读至 EOF 得完整 PDF → 写入 capture 临时文件 → `uploader.send_and_track` → 删除临时文件 |
| 单实例锁 | `_acquire_lock()` | 命名互斥体 `Local\LANPrintAgent` |
| 代理入口 | `run_agent(cfg)` | 单实例 → 托盘（失败降级无图标）→ RedirectListener + Agent.loop |

### 4.4 client/uploader.py — 上传与结果轮询

| 功能 | 代码块 | 说明 |
|---|---|---|
| 上传 | `upload(path, docname, copies, cfg)` | POST /print，返回 job_id；失败抛 TransportError / PayloadTooLarge |
| 轮询结果 | `poll_result(job_id, cfg)` | 每 poll_interval_sec 秒 GET /job/{id} 至终态；404 宽限 30 秒；超时抛异常 |
| 离线暂存 | `stash_offline(path, meta, cfg)` | 移入 offline 目录并写伴随 meta.json，供 agent 重发 |
| 完整流程 | `send_and_track(path, docname, copies, cfg)` | 上传 → 通知“已发送” → 轮询 → 通知“完成/失败”；连接失败走暂存；返回 0/1/2/3 |

### 4.5 client/notify.py — 结果通知（Session 0 → 用户会话）

| 功能 | 代码块 | 说明 |
|---|---|---|
| 通知落盘 | `emit_notification(notify_dir, ...)` | capture 处于 SYSTEM 会话（无 UI），写 JSON 通知文件；失败静默 |
| 通知消费 | `drain_notifications(notify_dir, callback)` | agent 侧读取并删除；>24h 陈旧丢弃 |
| 传统弹窗 | `message_box(...)` | ctypes MessageBoxW（TOP_MOST + SET_FOREGROUND） |
| Toast 通知 | `toast(...)` | 借 PowerShell AppUserModelID 调 WinRT Toast；失败降级 |
| 统一出口 | `notify_user(title, message, level)` | toast → 失败自动降级 message_box |
