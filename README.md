# LANPrint

**局域网跨设备虚拟打印机 · Windows**

把一台电脑上的真实打印机，共享给同一局域网内的其它 Windows 电脑直接使用。
客户端无需安装打印机驱动，只需安装一个安装包，就能像本地打印机一样打印。

</div>

---

## 功能特性

- **即装即用**：客户端安装包一键安装，自动注册虚拟打印机、自动启动后台代理，无需任何手动命令行操作；
- **像本地打印机一样打印**：客户端打印对话框出现虚拟打印机 `<服务端IP>_<共享名>`，Word / Excel / 浏览器 / 图片 / PDF 等任意可打印内容均可发送；
- **所见即所得**：打印内容由系统 `Microsoft Print To PDF` 渲染为标准 PDF 后传输，版式、纸张、横竖向与打印预览一致；
- **队列化打印**：多客户端同时打印时按先后顺序出纸，任务状态全程可查；
- **打印完成通知**：Windows Toast 提示“已发送 / 打印完成 / 打印失败原因”；
- **离线自动重发**：服务端暂时不可达时任务自动暂存，联网后自动补发，无需重打；
- **后台常驻 + 托盘状态灯**：开机自启，绿=在线、灰=离线、黄=有暂存；
- **零第三方组件**：客户端打印捕获采用 Windows 内置端口监视器回环方案，不捆绑任何第三方 DLL；
- **权限最小化**：仅安装/注册时需管理员权限，日常运行无需授权。

## 系统要求

- Windows 10 / 11 x64（服务端与客户端）
- 服务端需已安装可正常打印的真实打印机（USB / 网络均可）
- 服务端与客户端处于同一局域网

## 快速开始

```
服务端电脑：安装服务端包 → 选择共享的真实打印机 → 记住 IP/端口(17878)/共享名
客户端电脑：安装客户端包 → 填写服务端 IP/端口/共享名 → 完成
任意电脑：   打印 → 选“<服务端IP>_<共享名>”虚拟打印机 → 服务端出纸 → 收到完成通知
```

> ⚠️ 客户端安装时会强制校验能否连上服务端，连不上会中止安装。

## 工作原理

```
客户端电脑                                    服务端电脑
 ┌─────────────────────┐                     ┌──────────────────────┐
 │ 任意程序 → 打印      │                     │ HTTP 服务(17878)      │
 │   ↓ Microsoft Print  │                     │   ↓ 接收 PDF 落盘缓存  │
 │   To PDF 渲染成 PDF  │                     │   ↓ 打印队列 Worker    │
 │   ↓ 内置回环端口      │    HTTP /print      │ PDF 渲染 → GDI 写入    │
 │   (127.0.0.1:9100)   │ ──────────────────► │   ↓                    │
 │ agent 接收 PDF 并上传 │   GET /job 轮询结果 │ 真实打印机 → 出纸      │
 │   通知：已发送/完成   │ ◄────────────────── │ 完成自动删除源文件     │
 └─────────────────────┘                     └──────────────────────┘
```

关键设计：客户端使用 **Windows 内置 Standard TCP/IP 端口监视器**建立本机回环端口
（`127.0.0.1:9100`），配合常驻代理接收 spooler 送出的 PDF 字节流——完全兼容
v4 打印驱动，且不依赖任何第三方 DLL。方案演进详见 [项目开发说明](./docs/项目开发说明.md)。

## 项目结构

```
common/   两端共用：协议、multipart 解析、HTTP 工具、配置读写
server/   服务端：HTTP API、任务存储、打印队列、PDF 渲染 GDI 打印、配置向导
client/   客户端：虚拟打印机注册、上传轮询、常驻代理、通知
installer/ Inno Setup 安装脚本
build/    PyInstaller 打包配置与一键构建脚本
docs/     项目开发说明 / 功能模块说明 / 使用手册
tools/    测试脚本
```

## 从源码构建

前置：Python 3.11+、Inno Setup 6、项目内 `.pydeps`（已隔离的 PyInstaller 依赖）。

```bat
build\build.bat all        :: 生成 dist\lanprint_server_setup.exe 与 dist\lanprint_client_setup.exe
build\build.bat client     :: 仅客户端
build\build.bat server     :: 仅服务端
```

详细协议、模块说明与构建约定见 [docs](./docs)。
